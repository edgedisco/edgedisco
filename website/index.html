DESIGN PRINCIPLE / 05

DISCOVER
THE TOOLS.
NOT THE
CONVERSATIONS.

EdgeDisco uses local signals and normalized metadata to describe AI activity. Its collector and runtime adapters are designed to leave conversation content behind.

PRIVACY BOUNDARY◈ / 001
LOCAL SIGNALS→NORMALIZED EVIDENCE
BLOCKED FROM COLLECTION
PROMPTSRESPONSESCREDENTIALSAPI KEYS / TOKENSSOURCE CODERAW COMMAND LINES

Process and path details used for discovery are reduced to evidence such as names, relationships, and hashes. The OTLP outbox applies a separate strict allowlist.

START HERE / 09

MAKE SOME
DISCOVERIES.

Mac self-service setup installs the CLI and local services, then opens the dashboard. Python 3.9+ is required; the installer manages its own environment. Inspect the script before running it if you prefer.

  1. 01 / INSTALL FOR MAC
    EDGEDISCO_ARCHIVE_URL=https://codeload.github.com/edgedisco/edgedisco/tar.gz/refs/heads/main /bin/bash -c "$(/usr/bin/curl -fsSL https://raw.githubusercontent.com/edgedisco/edgedisco/main/install.sh)"
    The installer asks for confirmation and sets up per-user local services. Open a fresh Terminal window after installation.
  2. 02 / RUN THE DEMO
    edgedisco demo
    Runs controlled simulated workloads through the real discovery path. The demo attempts to open the local dashboard.
